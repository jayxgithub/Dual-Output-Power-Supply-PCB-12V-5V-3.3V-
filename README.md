# Dual-Output-Power-Supply-PCB-12V-5V-3.3V-
This project is a dual-output power supply PCB designed in KiCad that converts a 12V DC input into stable 5V and 3.3V outputs using LD1117 linear voltage regulators. It includes fuse protection, filtering capacitors, LED indicators, and multiple connectors, making it suitable for embedded systems, IoT devices, and microcontroller applications.
